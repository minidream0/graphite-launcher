# Smoky generated icon set

Generated with the built-in image_gen tool (not the API/CLI fallback), 2026-11-04. Five unmodified transparent PNG atlases, 16 icons each, in public/smoky-icons. Their 80 semantic IDs match the original Graphite catalog; both sets remain available. The first categories atlas is the style reference for all other sheets. Live cat motion remains editable SVG/CSS.

The renderer clips individual glyph bounds from smoky-icon-catalog.json. design/analyze-smoky-icons.py only reads alpha to locate transparent gutters and glyph bounds; it never edits image pixels. Generated grid spacing can drift, so cuts use the transparent valleys near each quarter instead of assuming exact equal cells. A runtime alpha transfer discards faint matte haze and low-alpha RGB noise without changing the generated icon colors.
